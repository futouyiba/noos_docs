# NOOS / 怒思｜命名与品牌候选记录

> **状态**：Working Note  
> **日期**：2026-08-27  
> **用途**：记录品牌候选、语义判断与外部重名风险。此文档不属于 Harness Runtime 架构。

---

## 1. 当前工作名

当前中文首选候选：

> **怒思**

英文内部项目名继续使用：

> **NOOS**

现阶段可以写作：

> **NOOS / 怒思**

但这只是产品与内部工作名候选，不代表已完成商标、域名、公司名、软件包名或全球品牌 clearance。

---

## 2. 为什么“怒思”目前优于其它候选

### 怒思

优点：

- 与 NOOS 的发音有记忆联系；
- “思”把语义明确拉回认知、推演、持续思考；
- “怒”保留强度和性格，不像普通企业咨询名；
- 很适合 Harness 的产品行为：不是一次回答，而是持续推进复杂工作；
- 口语上容易形成产品动作词，例如“让怒思继续跑”“开怒思模式”。

风险：

- “怒”天然带情绪和攻击性；
- 面向企业客户时需要通过视觉、文案和英文副标题弱化“愤怒”解释，强调 intense / persistent thinking；
- 仍需正式做同类软件、AI、商标、域名和 App Store 搜索。

当前判断：

> **最有辨识度，也最贴当前产品气质。**

---

## 3. 其它候选

### 努思

优点：

- 音近 NOOS；
- “努力思考”的含义自然；
- 更稳、更企业化。

问题：

- 品牌个性偏弱；
- 已存在长期使用“努思 / Nush”名称的企业管理咨询相关主体，存在现实占用；
- 容易让人联想到咨询、培训、人力服务，而不是 AI runtime / context harness。

当前判断：

> **可读但不优先。**

### 灵识

优点：

- 中文语义漂亮；
- 有“认知、感知、智能”的感觉；
- 与 AI 产品自然关联。

问题：

- 过于泛化；
- 现有 AI / 科技产品和概念中已有较多类似使用；
- 搜索归属和品牌差异化较弱；
- 与 NOOS 的语音关系断掉。

当前判断：

> **语义好，但可占有性与辨识度不足。**

### 怒撕

优点：

- 极强记忆点；
- 与 NOOS 发音梗最明显；
- 很适合开发者内部文化和 codename。

问题：

- 攻击性太强；
- “撕”更像破坏、争吵、互怼，不像组织复杂 AI 工作；
- 面向正式产品、企业知识和工作流场景时会限制品牌上限。

当前判断：

> **适合内部梗，不适合作为正式中文主品牌。**

---

## 4. 当前排序

暂定：

```text
怒思
>
努思
>
灵识
>
怒撕（正式品牌）
```

但如果只比较“内部昵称 / 开发者文化”，怒撕仍然非常强。

可以并存：

```text
正式候选：NOOS / 怒思
内部梗：怒撕模式
```

## 5. 英文 NOOS 的现实风险

当前已经发现一个值得重视的问题：

外部已经存在名为 `noos` 的 LLM agent reliability 相关 Rust / Python 项目，并且产品语义与 Harness 相邻，例如涉及 agent reliability、scope drift、circuit breaker、跨执行状态等方向。

这意味着未来公开产品化时，问题不只是“有人用了同一个英文单词”，而是：

> **同名项目处在相邻技术语义空间。**

因此 `NOOS` 暂时继续作为内部项目名没有问题，但正式发布前必须重新处理：

- 英文品牌 clearance；
- GitHub / PyPI / crates.io / npm 包名；
- 域名；
- 商标类别；
- 同类 AI 软件和 Agent 产品；
- SEO / 搜索唯一性。

不应因为中文名已确定，就默认英文名也能直接公开使用。

## 6. 当前品牌语义候选

如果继续使用“怒思”，建议不要解释成“愤怒地思考”，而应该围绕：

- 强度；
- 持续；
- 不轻易丢失上下文；
- 不停在第一层答案；
- 复杂工作持续推进。

一句比较贴当前 Harness 的内部定位：

> **怒思：让复杂 AI 工作持续思考下去。**

或者更接近产品架构：

> **怒思不替你回答一次问题；它负责让一项 AI 工作持续跑下去。**

这些都只是候选文案，不在当前阶段冻结。

---

## 7. 什么时候需要重新做命名决策

当前不建议继续花大量时间在 Naming 上。

以下条件之一出现时，再启动正式 Naming Sprint：

1. NOOS Harness MVP 已经验证核心价值；
2. 准备公开发布 Extension / Desktop App；
3. 准备注册公司、域名或商标；
4. 需要对外招募用户；
5. 英文 `NOOS` 冲突开始影响包名或产品分发。

正式 Naming Sprint 应包括：

```text
品牌语义
→ 同类产品检索
→ 商标初筛
→ 域名 / handle
→ 中英文组合
→ 发音与输入成本
→ SEO
→ 用户测试
→ 法律 clearance
```

## 8. 当前结论

> **中文工作名先用“怒思”；“怒撕”保留内部梗；英文 NOOS 暂作项目名，不视为已完成对外品牌确认。**
